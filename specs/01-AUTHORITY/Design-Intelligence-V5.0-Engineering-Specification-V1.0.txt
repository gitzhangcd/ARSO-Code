# Part VII｜Canonical Object Classification

E01 正式采用七类对象，而不是把所有东西都叫 immutable canonical object。

| Class                       | Semantics                       |
| --------------------------- | ------------------------------- |
| `CANONICAL_REVISION`        | 可演进内容的不可变版本                     |
| `IMMUTABLE_FACT`            | 已经发生的事实                         |
| `IMMUTABLE_ROOT`            | 稳定 identity root                |
| `IMMUTABLE_GRAPH_NODE`      | 图中的不可变状态节点                      |
| `SNAPSHOT`                  | 某个时点的闭包                         |
| `OPERATIONAL_CONTROL_STATE` | 可更新 orchestration/pointer state |
| `DERIVED_VIEW`              | 可删除重建的 projection               |

正式：

$$
\boxed{
HistoricalTruthImmutable
}
$$

但：

$$
\boxed{
OperationalPointersMayMutate
}
$$

ARSO Engineering 本身也区分 immutable domain records 与 mutable process records；后者通过明确 state transitions/events 管理，而非任意覆写。
