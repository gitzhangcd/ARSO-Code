# ARSO Literature Registry Changelog

## 2026-09-13 — V1.1 baseline

- Established GitHub literature-registry baseline.
- Added 122 stable `ARSO-LIT-xxx` records.
- Preserved V1.0 registry IDs and ARSO dispositions.
- Added metadata-normalization status: 77 primary-source/high-confidence records, 5 PDF/secondary records, 1 likely-resolved record, 39 unresolved records.
- Added explicit verification queue for unresolved and partially resolved bibliography.
- Frozen governance rules: IDs are stable; new discoveries do not automatically become normative; normative promotion requires an explicit literature-driven revision decision.
- Current baseline branch: `literature-registry-v1.1-baseline`.

## Maintenance policy

Future updates should record additions, metadata corrections, deduplication/alias merges, supersession/withdrawal changes, disposition changes, and any literature item that creates possible normative pressure on ARSO.
