# ARSO Literature Registry

This directory is the GitHub baseline for the ARSO literature evidence system.

## Current authority

- `registry/ARSO_Literature_Registry_V1.1_Metadata_Normalized.md` — current human-readable registry SSOT for this baseline.
- `queue/ARSO_Literature_Registry_V1.1_Verification_Queue.md` — unresolved/partially resolved bibliographic verification queue.
- `CHANGELOG.md` — literature-registry change log.

## Governance

1. `ARSO-LIT-xxx` IDs are stable and must not be renumbered because of sorting or later insertions.
2. Newly discovered work enters as `REFERENCE_ONLY` / pending review by default.
3. Bibliographic verification, scientific relevance, and normative adoption are separate dimensions.
4. Promotion to `ADOPTED_NORMATIVE` requires an explicit ARSO literature-driven revision decision; Daily/Weekly literature discovery does not directly modify the ARSO Master Specification.
5. Superseded, withdrawn, corrected, or replaced papers remain in lineage with status metadata rather than being silently deleted.

## Maintenance cadence

`Daily discovery → Weekly registry consolidation → Monthly scientific rebaseline → Rare normative revision`

Baseline established: 2026-09-13.
